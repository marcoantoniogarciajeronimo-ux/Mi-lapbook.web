📚 Mis Conceptos

📄 HTML +

¿Qué es?

HTML significa Lenguaje de Marcado de Hipertexto. Es el esqueleto de cualquier página web. Con él creas la estructura: títulos, párrafos, imágenes, enlaces y listas. Sin HTML no hay contenido que mostrar.

Puntos importantes:

  • Es el lenguaje base de todas las páginas web
  • Usa etiquetas como <h1>, <p>, <img> y <a>
  • Define qué contenido aparece y en qué orden
  • No es un lenguaje de programación, sino de marcado
🎨 CSS +

¿Qué es?

CSS significa Hojas de Estilo en Cascada. Se encarga de la apariencia visual: colores, fuentes, tamaños, márgenes y cómo se organizan los elementos en pantalla. Es lo que hace que tu página se vea bonita y ordenada.

Puntos importantes:

  • Da color, diseño y estilo a lo que creaste con HTML
  • Permite que tu página se vea bien en celular y computadora
  • Separa el contenido de su apariencia visual
  • Facilita mantener el mismo estilo en todo tu sitio
⚡ JavaScript +

¿Qué es?

JavaScript es el lenguaje de programación del navegador. Le da vida a tu página: puedes hacer que algo cambie al dar clic, validar formularios, crear animaciones y mucho más.

Puntos importantes:

  • Agrega interactividad: cuando el usuario hace algo, la página responde
  • Es el único lenguaje que funciona directamente en el navegador
  • Permite crear efectos, juegos y aplicaciones completas
  • Junto con HTML y CSS, forma el trío fundamental de la web
🗄️ SQL +

¿Qué es?

SQL significa Lenguaje de Consulta Estructurado. Sirve para comunicarte con las bases de datos: guardas información, la buscas, la actualizas y la eliminas. Es como un archivador digital muy rápido y organizado.

Puntos importantes:

  • Permite guardar y recuperar información de forma ordenada
  • Se usa en sistemas como MySQL, PostgreSQL y SQLite
  • Organiza la información en tablas con filas y columnas
  • Es indispensable para aplicaciones que guardan datos de usuarios
🌹 Jinja2 +

¿Qué es?

Jinja2 es un motor de plantillas para Python. Funciona como un puente: permite que la información de tu programa Python aparezca automáticamente en tu página web sin tener que escribirla una por una.

Puntos importantes:

  • Conecta tu código Python con tu página web
  • Muestra información que cambia sin tener que editar el HTML
  • Funciona perfectamente con Flask
  • Hace que crear páginas dinámicas sea mucho más fácil
